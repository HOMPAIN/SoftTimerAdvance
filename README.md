# SoftTimerAdvance

Это библиотека для Arduino-проектов. Она предназначена для организации процессов во времени за счёт функционала программных таймеров.

Основным критерием при разработке данной библиотеки была простота использования. При этом библиотека обладает широким функционалом и возможностями, но они реализованы так, чтобы не усложнять базовое использование.

## Возможности

- Таймеры
- Отложенный запуск (запуск с задержкой)
- Таймауты
- Псевдопотоки / задачи
- Мониторинг производительности

## Как использовать

При запуске программы создаётся менеджер таймеров `SoftTimerManager`, который затем работает в бесконечном цикле и вызывает функции таймеров.

Функция, которая должна вызываться по таймеру, просто добавляется в менеджер, и он сам вызывает её в нужное время:

```cpp
// Функция таймера, вызывается раз в 500 миллисекунд
void Timer500ms()
{
  Serial.println("500ms");
}

// Добавление таймера в менеджер с периодом 500 мс
ST.AddTimer(Timer500ms, 500);
```

Более подробные инструкции реализованы на базе примеров. Примеры сгруппированы по темам, каждый показывает одну возможность.

**Timer — таймеры**

- **Timer/Basic** — базовый пример использования таймеров
- **Timer/ParameterToTimer** — передача параметра в таймер
- **Timer/DynamicAddDelete** — динамическое добавление и удаление таймеров
- **Timer/SetPeriod** — изменение периода таймера
- **Timer/Freeze** — остановка и продолжение работы таймера
- **Timer/Reset** — сброс таймера
- **Timer/ForceCall** — внеочередной вызов таймера
- **Timer/GetDelay** — время до срабатывания таймера
- **Timer/Microseconds** — таймер с периодом в микросекундах

**DelayCall — отложенный запуск**

- **DelayCall/Basic** — базовый пример использования запуска с задержкой
- **DelayCall/Parameter** — отложенный запуск функции с параметром
- **DelayCall/Cancel** — отмена отложенного запуска
- **DelayCall/Reuse** — многократное использование одного отложенного запуска

**Timeout — таймауты**

- **Timeout/Basic** — базовый пример использования таймаута
- **Timeout/Stop** — запуск и остановка таймаута
- **Timeout/SetTimeout** — изменение времени таймаута

**Task — задания / псевдопотоки**

- **Task/Basic** — базовый пример работы с заданиями
- **Task/TwoTasks** — одновременная работа двух заданий
- **Task/StartAbort** — остановка и повторный запуск задания

**Telemetry — мониторинг производительности**

- **Telemetry/CPULoad** — загрузка процессора функциями таймеров
- **Telemetry/WorkTime** — время работы функции таймера
- **Telemetry/WatchDog** — контроль слишком долгих функций
- **Telemetry/LoadLed** — светодиод загрузки процессора
- **Telemetry/PoolUsage** — сколько памяти буфера занимают таймеры

**Sleep — ожидание и сон между таймерами**

- **Sleep/Delay** — время до следующего срабатывания таймера
- **Sleep/ESP32LightSleep** — сон процессора ESP32 между срабатываниями таймеров
