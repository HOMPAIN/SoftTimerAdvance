# SoftTimerAdvance

Это библиотека для Arduino-проектов. Она предназначена для организации процессов во времени за счёт функционала программных таймеров.

Основным критерием при разработке данной библиотеки была простота использования. При этом библиотека обладает широким функционалом и возможностями, но они реализованы так, чтобы не усложнять базовое использование.

## Возможности

- Таймеры
- Отложенный запуск (запуск с задержкой)
- Таймауты
- Псевдопотоки / задачи
- Мониторинг производительности

## Как использовать

При запуске программы создаётся менеджер таймеров `SoftTimerManager`, который затем работает в бесконечном цикле и вызывает функции таймеров.

Функция, которая должна вызываться по таймеру, просто добавляется в менеджер, и он сам вызывает её в нужное время:

```cpp
// Функция таймера, вызывается раз в 500 миллисекунд
void Timer500ms()
{
  Serial.println("500ms");
}

// Добавление таймера в менеджер с периодом 500 мс
ST.AddTimer(Timer500ms, 500);
```

Более подробные инструкции реализованы на базе примеров:

- **Timer/Basic** — базовый пример использования таймеров
- **Timer/DynamicAddDelete** - динамическое добавление удаление таймеров
- **Timer/ParameterToTimer** - передача параметра в таймер
- **DelayCall** — базовый пример использования запуска с задержкой
- **Timeout** — базовый пример использования таймаута
- **Task** — базовый пример работы с заданиями/псевдо потоками
- **ESP32Sleep** — сон процессора ESP32 между срабатываниями таймеров
